# StockAI – ניתוח ואיתותי קנייה/מכירה למניות בארה"ב

מערכת מקומית (רצה אצלך במחשב, בדפדפן) שסורקת את השוק האמריקאי, מנתחת גרפים תוך-יומיים, קוראת כתבות
ומחזירה **הסתברות באחוזים** שהמניה תעלה באופק שבחרת, יחד עם המלצה, סטופ ויעד.

## התקנה והרצה (Windows)
1. צריך Python 3.10 ומעלה (python.org, לסמן "Add to PATH").
2. לחילוץ ה-ZIP לתיקייה, למשל `C:\projects\stock_ai`.
3. דאבל-קליק על **`run.bat`**. בהרצה הראשונה הוא מתקין את הספריות (כ-2 דקות), ואחר כך הדפדפן נפתח ב-`http://localhost:8501`.

ב-Mac/Linux: `./run.sh`

> לא צריך מפתח API: הנתונים מגיעים מ-Yahoo Finance ו-Google News בחינם (עלולים להתעכב בכמה דקות).

## מה יש בממשק
| לשונית | מה היא עושה |
|---|---|
| 📈 ניתוח מניה | בוחרים מניה, אינטרוול (1 דקה עד שבועי), אופק תחזית ותדירות רענון. מקבלים מד הסתברות, המלצה, סטופ/יעד, גרף נרות עם EMA/VWAP/בולינגר/תמיכות, RSI, MACD, נפח, וגם את הסיבות. |
| 🔎 סורק מניות | מריץ את כל הניתוח על רשימת מעקב ומדרג לפי חוזק האיתות. יש רשימות מוכנות. |
| 🌎 מגמות שוק | מדדים, VIX, רוטציית סקטורים ורוחב שוק. |
| 📰 חדשות | כתבות שוק כלליות עם ציון סנטימנט. |
| 🧪 בדיקה היסטורית | Walk-forward backtest: דיוק, AUC, אחוז הצלחה, עקומת תשואה מול קנה-והחזק, וטבלת כיול. |

## ניטור ברקע + התראות לטלפון
```
monitor.bat                                   # רשימת המעקב מההגדרות, כל 5 דקות
monitor.bat --tickers NVDA TSLA --every 2 --interval 1m --horizon 15
```
כשהמערכת מזהה איתות חזק חדש היא משמיעה צפצוף, ואם הגדרת טלגרם היא גם שולחת הודעה.
**הגדרת טלגרם:** פותחים בוט דרך @BotFather ומקבלים token. שולחים לבוט הודעה, ואת ה-chat id מוצאים ב-
`https://api.telegram.org/bot<TOKEN>/getUpdates`. את שניהם מזינים בסרגל הצד ושומרים.

## איך ההסתברות מחושבת (בקצרה)
- **25+ אינדיקטורים**, שמהם נבנים משתנים ל**מודל ML** (רגרסיה לוגיסטית + Gradient Boosting). המודל מאומן על ההיסטוריה של המניה הספציפית.
- **Walk-forward**: המודל נבדק רק על תקופות שלא ראה, ומזה נמדד אם יש לו יתרון אמיתי (AUC).
- **כיול**: ההסתברות מכוילת לפי התוצאות מחוץ למדגם. אם אין יתרון מוכח, היא נמשכת אוטומטית לשיעור הבסיס, כך שלא יוצג "ביטחון" מזויף.
- **שכבות התאמה**: סנטימנט חדשות משוקלל לפי טריות, מצב השוק (SPY, VIX), אישור מטווח זמן גבוה ותבניות נרות.

## טיפים
- כדאי להתחיל מ-`5m` עם אופק 12 נרות (שעה), או `15m` עם אופק 8 (שעתיים). ב-`1m` יש הרבה רעש.
- צריך להסתכל על **AUC**: מעל 0.55 יש יתרון סטטיסטי, ומתחת ל-0.53 עדיף לא לסמוך על האיתות.
- ההגדרות נשמרות ב-`settings.json`.
